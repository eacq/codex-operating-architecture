# UI UX Pro Max → Visual Design Agent 适配层

## 核心职责

UI UX Pro Max 是视觉设计 agent 的主设计系统核心，不直接输出最终文件格式或渲染器。它先决定视觉策略，再由格式路线落地。它提供：

- 产品/领域匹配
- 视觉风格与反模式
- 色彩和字体组合
- 信息密度、变化度和动效强度
- 图表与 UX 检查项

视觉设计 agent 的格式路线负责把这些核心决策映射到图片、PPT、Draw.io、架构图、科研图和信息图，并保留各格式自己的编辑性、实际渲染和数据保真门禁。

## 适配流程

1. 所有视觉任务先运行 `Invoke-UiUxProMaxDesignSystem.ps1`，记录源仓库和 commit。
2. 读取 `MASTER.md`，识别推荐的模式、风格、颜色、字体、密度和反模式。
3. 根据任务格式建立本地覆盖规则；UI/SaaS 推荐不能直接套用到科研图或机械 PPT。
4. 将设计系统转换为 `design_brief.md`、布局映射和素材/组件规则。
5. 生成并实际渲染最终文件。
6. 根据最终结果回改区域、框、节点、图片、连线、字号和留白。

## 机械科研默认覆盖

- 首选 Swiss/Editorial、Flat Scientific、Balanced Minimal、轻量 2.5D 机械线稿。
- 首选深蓝、浅蓝、白色和少量橙色；避免 AI 紫/粉渐变和玻璃拟态。
- 内容主题优先精密加工、磨削、齿轮、CAM、工业软件、大数据、AI 和数学建模。
- 图片比例、卡片数量、容器数量和布局间距以最终渲染美观与清晰为准。

## 失败与回退

如果 UUPM 无法匹配领域，保留“未匹配”证据并使用本地覆盖模板；不得把通用 SaaS 设计系统当成事实或强制套用。若适配层失败，仍必须继续执行所选路线的确定性渲染和验证。
