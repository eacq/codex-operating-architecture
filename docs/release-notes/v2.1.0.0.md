## What's new / 本次更新

### English

- Rebase the private release line so the current Agent architecture is published as the unified `2.1` baseline.
- Upgrade the Global Experience Agent with local book-shelf learning from `F:/codex/book`, storing only derived metadata and review lenses while source books remain private and ignored.
- Add Darwin/SkillOpt-style skill-evolution optimization with strict improvement scoring, safety checks, deterministic tests, and a Brian Arthur technology-evolution lens.
- Add `ReviewAgent` and the `agent-reviewed` typed exit for book-derived review checkpoints without direct structural mutation.
- Unify Codebase Memory MCP/UI on `127.0.0.1:9749`, enforce the canonical `F-codex` cache, and clean stale non-`F-codex` indexes.
- Regenerate Agent architecture diagrams and mappings for four interfaces, nine typed exits, 23 specialist Agents, five concept Agents, and 50 handoffs.

### 中文

- 将私有发布线重新归一：以当前 Agent 架构内容作为统一的 `2.1` 基线发布。
- 为全局经验 Agent 增加 `F:/codex/book` 本地书架学习，只保存派生元数据和评审透镜，书籍原文继续保持私有并被忽略。
- 新增 Darwin/SkillOpt 风格的 skill 演化优化，包含严格提升评分、安全检查、确定性测试和布莱恩·阿瑟技术演化透镜。
- 新增 `ReviewAgent` 与 `agent-reviewed` 类型出口，用于承接书籍派生的评审检查点，且不直接修改结构。
- 统一 Codebase Memory MCP/UI 到 `127.0.0.1:9749`，强制使用 canonical `F-codex` 缓存并清理陈旧的非 `F-codex` 索引。
- 重新生成 Agent 架构图与映射，覆盖 4 类接口、9 个类型出口、23 个 specialist Agents、5 个 concept Agents 与 50 条 handoff。
