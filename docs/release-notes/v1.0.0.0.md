# v1.0.0.0 / v1.0

## English

This is the reset baseline for the current Codex Global Experience Agent
system. It contains the verified root Agent architecture, registered concept
and specialist Agents, bounded child-Agent contracts, LoopX project control
plane, lifecycle and publication gates, knowledge workflows, and validation
tools.

The private repository is published with the Git tag `private-v1.0`; the public
repository is published separately with the Git tag `v1.0` after the public
safety audit.

## Chinese / 中文

这是当前 Codex 全局经验 Agent 系统的重置基线，包含已验证的根 Agent 架构、已注册的
概念与专业 Agent、受限的子 Agent 契约、LoopX 项目控制平面、生命周期与发布门禁、
知识工作流及验证工具。

私有仓库使用 Git 标签 `private-v1.0` 发布；通过公共安全审计后，公共仓库单独使用
Git 标签 `v1.0` 发布。
