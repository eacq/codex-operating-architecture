# v1.0.1.0

## English

Verified automatic feature iteration for the Codex Global Experience Agent system.

- Add an auditable autonomous capability decision policy
  (`config/agent-autonomous-capability-decision-policy.json`) with an
  autonomous-selection-first plan, per-capability owners and gates,
  negative-trigger suppression, and a no-authority-elevation rule; the
  capability plan is wired into the intent router and harness save-point output
  with a dedicated pressure test.
- Add verified validation-writeback timing evidence: one real isolated
  replacement with the ReducedDuplicateValidation profile completed
  (`full-plus-balanced-stability`; balanced stability profile 12.66s vs
  baseline pass-2 mean 212.5s, about 94% reduction) while Full two-pass
  validation remains the mandatory closeout and publication gate.
- Fix UTF-8 BOM violations in timing-analysis data files and generated
  documentation (writers now emit UTF-8 without BOM) and fix the
  isolated-iteration Git bundle argument bug on Windows PowerShell 5.1.
